# 領収書ビューア (QR領収)

QR領収アプリが発行するQRコードを開くと表示される、領収書の描画ページです。

## 仕組み

領収書の内容は **URLのフラグメント(`#` 以降)** に圧縮して埋め込まれています。
このページはそれを展開して Canvas に描画するだけで、**サーバは領収書の内容を一切受け取りません**
(フラグメントはHTTPリクエストに含まれないため)。

```
https://r.akarifortune.net/#1.<deflate+base64urlのペイロード>
```

- `1.` = raw deflate + base64url / `0.` = base64url(無圧縮)
- 外部ライブラリなし。静的HTML1枚で完結します

## 再ホストについて

領収書は確定申告などで後から見返されることがあります。
万一このドメインが使えなくなっても、**データは利用者のURLの中に残っている**ため、
このリポジトリの `index.html` をどこかに置けば表示を復元できます。
